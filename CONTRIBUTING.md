# Contributing to directory awareness

Thank you for considering a contribution to a project whose implementation
fits comfortably inside a fortune cookie.

Good contributions:

- Clearer instructions for the listing commands and their Pro alias.
- Better documentation, accessible visuals and tasteful jokes.
- Corrections to technical claims.

Please keep the product intentionally small. No installer, background agent,
telemetry, runnable destructive examples, dependency tree or payment integration.
Deletion commands may be named in the parody roadmap with a clear warning.

Humour should target overblown software marketing, not individual people.
Never include real directory listings, private paths or credentials in examples.

Before proposing a change, check that the listing commands remain easy to find and
that the README still explains the limitations honestly.
